VTPlay {VERSION} — Windows 便携版
=====================================

用法
----
双击 vtplay.exe 即可运行；把视频文件拖进窗口即可播放。

不需要安装，也不写系统目录。配置存放在
    注册表  HKCU\Software\VTPlay\VTPlay
    %LOCALAPPDATA%\VTPlay
删掉本目录即可卸载。

功能
----
· 播放常见格式（H.264 / H.265 / AV1 等，依赖随包 FFmpeg）
· 播放列表 / 最近打开 / 循环模式 / 倍速 / 音量
· 逐帧前进后退（Ctrl+← / Ctrl+→），seek（← → 5 秒，Shift+← → 1 秒）
· 截图（Ctrl+S，可选「仅画面」或「含界面」）
· 导出 / 转换（Ctrl+E，调用随包 ffmpeg，无需另装）
· 深色界面、全屏（F）、始终置顶、设置（F5）
· 按 F10 打开菜单：↑↓ 选择、→ 进子菜单、← 返回

日志
----
%LOCALAPPDATA%\VTPlay\VTPlay\vtplay.log（超过 1MB 自动轮转）。
反馈问题请附上这个文件。

已知限制
--------
· 逐帧后退需要回到关键帧重新解码，每次约 150~200 毫秒
· 截图「仅画面」模式的分辨率是解码输出尺寸，不是源片原始分辨率
· 仅支持 Windows 64 位

许可
----
本程序以 Qt（LGPLv3）构建。随包的 ffmpeg 为 GPL 构建，以独立进程方式调用，
不构成衍生作品。两者的许可证全文见 Qt 与 FFmpeg 项目官网。
