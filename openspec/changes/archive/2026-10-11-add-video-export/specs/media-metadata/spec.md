## ADDED Requirements

### Requirement: 媒体元数据字段

系统 SHALL 在打开媒体后提供完整的元数据，除既有的时长、分辨率、帧率与编解码器名称外，MUST 至少额外包含：

- 文件名（不含目录）
- 文件大小（字节）
- 视频码率
- 音频采样率、声道数、音频码率

上述字段 MUST 在 core 层解析一次并对外暴露，供界面显示与导出估算共用，UI 层 MUST NOT 重复解析媒体容器。

#### Scenario: 打开文件后元数据完整

- **WHEN** 用户打开一个 H.264/AAC 的 MP4 文件
- **THEN** 系统可提供文件名、文件大小、分辨率、帧率、视频码率、音频采样率、声道数、音频码率与时长

#### Scenario: 字段缺失时的降级

- **WHEN** 源文件未提供某字段（例如码率缺失）
- **THEN** 该字段以"不可用"表示且不显示为 `0` 或负数，其余字段仍正常提供

### Requirement: 面向展示的格式化

系统 SHALL 提供统一的格式化表示，供界面与导出对话框复用：

- 码率：以 `Mbps` / `kbps` 显示（如 `54 Mbps`）
- 体积：以 `MB` / `GB` 显示（如 `157 MB`）
- 分辨率与帧率：`2160×3840 · 60fps` 形式
- 声道：以可读形式显示（如 `立体声`）

#### Scenario: 码率格式化

- **WHEN** 视频码率为 54207233 bps
- **THEN** 展示为 `54 Mbps`（紧凑形式为 `54Mbps`）

#### Scenario: 体积格式化

- **WHEN** 文件大小为 165306099 字节
- **THEN** 展示为 `158 MB`（紧凑形式为 `158MB`）

#### Scenario: 规格摘要一行显示

- **WHEN** 界面需要一行展示媒体规格
- **THEN** 输出形如 `2160×3840 · 60fps · 54Mbps · 158MB` 的摘要，缺失字段自动省略

#### Scenario: 字段不可用时降级

- **WHEN** 容器未提供码率等字段（值为 0）
- **THEN** 对应项从摘要中省略，单独查询该字段时返回 `—`，而不是显示 `0` 或负数
