# player-ui

## ADDED Requirements

### Requirement: 品牌视觉主题
UI SHALL 采用深色 + 荧光绿品牌主题：主背景 `#0D0D0D`、面板 `#1A1A1A`、强调色 `#D4FF00`、控件圆角 8–12px、时间码等宽字体。视觉 token 集中定义。

#### Scenario: 主题一致性
- **WHEN** 应用启动进入主界面
- **THEN** 界面为深色主题，进度条、播放态高亮、焦点态均使用荧光绿强调色

### Requirement: 主界面布局
主界面 SHALL 包含：视频渲染区（空置时显示 VTPlay logo 占位与拖拽提示）、底部悬浮控制条（播放/暂停、进度条、时间码、音量、倍速、全屏按钮）。控制条在无鼠标交互数秒后自动隐藏，移动鼠标时重现。

#### Scenario: 打开文件前
- **WHEN** 应用启动且未打开文件
- **THEN** 视频区显示 logo 占位画面与"拖入文件或点击打开"提示

#### Scenario: 播放中控制条自动隐藏
- **WHEN** 播放中鼠标静止 3 秒以上
- **THEN** 控制条淡出隐藏；鼠标移动后立即重现

### Requirement: 文件打开与拖拽
UI SHALL 支持文件选择对话框打开（按钮 + 快捷键 Ctrl+O）以及拖拽文件到窗口打开。

#### Scenario: 拖拽打开
- **WHEN** 用户将一个 MP4 文件拖入窗口
- **THEN** 应用立即开始播放该文件

### Requirement: 进度条交互
进度条 SHALL 支持点击跳转与拖拽跳转，拖拽过程中时间码实时预览目标位置，松开后执行精准 seek；拖拽中画面显示目标位置帧（v2 可降级为仅时间码预览）。

#### Scenario: 拖拽进度条
- **WHEN** 用户按住进度条滑块拖动
- **THEN** 时间码跟随显示目标时间，松开后画面在 1 秒内跳到目标帧

### Requirement: 音量与倍速控件
控制条 SHALL 提供音量滑块（0–100%，静音切换）与倍速选择（0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x）。

#### Scenario: 调节音量
- **WHEN** 用户拖动音量滑块到 30%
- **THEN** 输出音量立即变为 30%，↑↓ 键与滑块状态保持同步

### Requirement: 全屏
UI SHALL 支持 F 键与双击视频区切换全屏，全屏下控制条行为不变。

#### Scenario: 进入全屏
- **WHEN** 播放中用户按 F
- **THEN** 窗口切换为全屏无边框，视频铺满屏幕，再按 F 恢复
