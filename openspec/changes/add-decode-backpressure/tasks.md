## 1. 帧队列：保留窗口（D1 / D3）

- [x] 1.1 `setKeepAfter(double pts)`：基点 + 帧数（`kKeepCount = 4`）；传负数撤销窗口
- [x] 1.2 `pushVideo` 超时兜底改为 `dropOldestDroppableLocked()`：窗口内的帧不丢
- [x] 1.3 窗口内全受保护时不再丢、直接推入（容量可临时超出，上界 = 容量 + kKeepCount）
- [x] 1.4 内存上界写在代码注释里

> **实施中发现的关键事实**：`pushVideo` 早已不是「直接丢最旧」，而是
> **「阻塞 100 ms → 超时后丢最旧」**（超时兜底是为了避免经包队列反向卡死 demux）。
> 暂停时消费者停摆，于是每 100 ms 稳定丢一帧，正好把显示位置之后的帧逐个挤掉。
> 因此保留窗口的正确落点是**让超时兜底跳过窗口内的帧**，而不是另起一套阻塞逻辑。
