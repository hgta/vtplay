## ADDED Requirements

### Requirement: Windows 8.1 x64 构建的功能面完整

面向 Windows 8.1 x64 的构建 SHALL 提供与主干一致的播放与导出能力：打开 / 播放 / 暂停 / seek / 逐帧步进 / 倍速 / 音量、截图、分享导出，以及修复导出（诊断 → 方案 → 预览 → 执行 → 取消）。

#### Scenario: 播放链路可用
- **WHEN** 在 Windows 8.1 x64 上用该构建打开一个视频文件
- **THEN** 画面与声音输出正常，且 seek、逐帧前进/后退、倍速、音量调节均可用

#### Scenario: 修复导出可完成
- **WHEN** 用户完成诊断后点击「按此方案导出」
- **THEN** 对话框进入「正在导出…」并显示进度，导出结束后输出文件存在且可播放

#### Scenario: 修复导出可取消
- **WHEN** 导出进行中用户点击「取消导出」
- **THEN** 子进程被终止、半成品输出被删除、临时目录被清理，界面回到未导出状态

### Requirement: 依赖闭包不得包含目标系统缺失的组件

面向 Windows 8.1 的构建，其产物内所有可执行文件与动态库 MUST NOT 静态导入 Windows 8.1 不提供的 DLL 或函数（典型：`d3d12.dll`、`SetThreadDescription`）。该约束 MUST 能在没有目标系统的机器上自动校验。

#### Scenario: 门禁拦住不合规产物
- **WHEN** 对含 `d3d12.dll` 导入的产物运行依赖闭包校验
- **THEN** 校验失败，并指出导入该 DLL 的文件名与缺失的组件名

#### Scenario: 函数级硬导入同样被拦截
- **WHEN** 某个动态库从 `kernel32.dll` 硬导入 `SetThreadDescription`
- **THEN** 即使 DLL 级清单看起来干净，校验仍然失败并指出函数名

#### Scenario: 合规产物放行
- **WHEN** 产物内全部导入都落在目标系统可用集内
- **THEN** 校验通过，并输出被扫描的二进制数量作为可复核证据

### Requirement: 渲染后端不可用时自动降级

当默认图形后端无法初始化时，系统 SHALL 降级到软件渲染并继续运行，MUST NOT 表现为空白窗口、静默退出或仅留一条系统级错误。

#### Scenario: 图形驱动能力不足时仍可播放
- **GIVEN** 目标机的 OpenGL 版本低于 Qt Quick 所需，且本构建不带 ANGLE
- **WHEN** 用户启动程序并打开视频
- **THEN** 窗口正常出现、视频可播放（软件渲染），交互不阻塞

#### Scenario: 降级必须留痕
- **WHEN** 发生后端降级
- **THEN** 日志记录实际使用的后端与降级原因，便于用户反馈时定位

### Requirement: 运行环境问题必须可诊断

当前置条件不满足时（操作系统版本低于最低要求、转码器缺失、无可用音频设备、渲染后端不可用），系统 SHALL 记录一条包含「缺什么 + 需要什么」的日志，并在界面可及时给出可见提示。

#### Scenario: 系统版本低于最低要求
- **WHEN** 程序在不满足最低系统要求的机器上启动并成功加载
- **THEN** 日志与界面提示均说明最低系统要求，而不是仅表现异常

#### Scenario: 转码器缺失
- **WHEN** 找不到可用的 ffmpeg
- **THEN** 导出入口置灰，并在对话框内说明原因与下一步（去设置指定路径）

#### Scenario: 无可用音频设备
- **WHEN** 系统没有可用音频输出设备
- **THEN** 日志明确记录该情况，视频播放不受影响

### Requirement: 最低系统声明与实际依赖一致

每个发布产物 SHALL 声明其最低 Windows 版本，且该声明 MUST 与实测的依赖闭包一致——不得声明得比实际更宽松。

#### Scenario: 声明不得过度承诺
- **WHEN** 某产物的依赖闭包包含仅在 Windows 10 提供的组件
- **THEN** 该产物的最低系统声明 MUST 为对应 Windows 10 版本，不得声明支持 Windows 8.1

#### Scenario: Win8.1 构建的声明可核对
- **WHEN** 查看 Windows 8.1 构建的发布说明
- **THEN** 其中给出的最低系统与该产物的依赖闭包校验结果一致
